# Snapchat Clone 📸

Ek fun aur entertaining **Snapchat clone** jo sabke entertainment ke liye banaya gaya hai. Yeh project Snapchat ke core features ko replicate karta hai — snaps bhejna, stories, aur ephemeral messaging ka maza.

## 🎯 About The Project

Yeh project ek **entertainment-focused** Snapchat clone hai jisme maine Snapchat ke popular features ko recreate karne ki koshish ki hai. Iska maqsad hai ek smooth, fun aur engaging social experience dena — bilkul Snapchat jaisa, but apne style mein.

## ✨ Features

- 📷 **Photo & Video Snaps** — Snaps capture karo aur bhejo
- ⏱️ **Ephemeral Messages** — Messages jo view hone ke baad delete ho jate hain
- 📖 **Stories** — 24-hour stories jo followers dekh sakte hain
- 👻 **Snap Streaks** — Doston ke saath streaks maintain karo
- 🎨 **Filters & Lenses** — Fun filters aur effects
- 💬 **Chat** — Real-time messaging
- 👥 **Friends System** — Friends add karo aur manage karo
- 🔔 **Notifications** — Real-time notifications

## 🛠️ Tech Stack

> (Yahan apne actual tech stack ke hisaab se edit karo)

- **Frontend:** React / React Native / Flutter
- **Backend:** Node.js / Express
- **Database:** MongoDB / Firebase
- **Authentication:** Firebase Auth / JWT
- **Storage:** Cloudinary / Firebase Storage
- **Real-time:** Socket.io / Firebase Realtime DB
